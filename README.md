# Cyber Byte Peru

Sitio de marketing mobile-first construido con Next.js App Router, TypeScript y Tailwind CSS.

## Desarrollo

- `bun install`
- `bun run dev` en http://localhost:3000

## Produccion

- `bun run build`
- `bun run start`

## Archivos clave

- `src/app/page.tsx`: pagina completa con header, hero, servicios, proceso, testimonios, CTA y footer.
- `src/app/globals.css`: tema visual, variables de marca y microinteracciones.
- `src/app/layout.tsx`: metadata y layout raiz.
- `postcss.config.mjs`: integracion de Tailwind CSS v4.
